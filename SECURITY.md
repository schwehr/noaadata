# Security Policy

## Supported Versions

The following versions of `noaadata` are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.46+   | :white_check_mark: |
| < 0.46  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `noaadata`, please do NOT open a public GitHub issue. Instead, report it directly to the maintainers:

- **Email**: Kurt Schwehr <schwehr@gmail.com>

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof-of-concept payload.

We will respond within 48 hours and work with you to resolve the issue before public disclosure.
