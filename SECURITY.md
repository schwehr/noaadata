# Security Policy

**note**: There is **NOT** currently any support for `noaadata` (security or
otherwise). This is a placeholder for the future.

## Supported Versions

The following versions of `noaadata` are currently supported with security
updates:

Version | Supported | ------- | ------------------ | 0.46+ | :white_check_mark:
| < 0.46 | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability within `noaadata`, please open a public
GitHub issue.

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof-of-concept payload.
